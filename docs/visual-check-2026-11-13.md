## 눈에 띈 것 (고치지 않음)

1. **한글 화면에 영문 이름이 섞인다.** 생산·연구 탭과 복기의 "첫 유닛"에 `Militia`가 영문으로 나온다. `site/app.js`의 `names` 표에 없는 이름이 운영 보고서에 80종쯤 있다(예: Militia 19회, Padded Archer Armor 22회, Scale Mail Armor 21회, Man-at-Arms 13회, Trebuchet 9회, Palisade Gate 12회). `Technology 1451`·`1452`·`1483`, `Building 2556`처럼 이름 대신 번호로 나오는 항목도 있다.
2. **Arena 본진 확대에서 성벽 표시가 겹친다.** 시작 성벽마다 표식과 글자가 붙어 글자를 읽기 어렵고 다른 건물을 가린다(360px, #520386901). APP-07 범위다.
3. **가까운 건물의 글자가 겹친다.** 데스크톱 본진 확대에서 집·병영 글자가 서로 겹친다(#520592057, 10:00). APP-07 범위다.

## 확인하지 않은 것

- 실제 휴대폰·iOS Safari, 실제 터치와 끌기, 화면 회전.
- 슬라이더 끌기, 페이지를 숨겼을 때 재생 정지, 문명 아이콘 누르기·호버 설명.
- 계정·수집 창, 유저 검색, 다른 프로필, "지금 수집".
- `map_view`·엔진 수입이 없는 옛 개정 경기의 안내 문구, 데스크톱 건설 맵 표시 선택.
- 320px 이하, 430~1280px 사이 폭.
