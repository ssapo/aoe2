# SSAPO AoE2 리플 분석

**Age of Empires II: Definitive Edition 1v1 경기 복기 웹앱**입니다. 공개 경기 기록과 리플을 분석해 나와 상대의 전개를 비교합니다.

**[사이트에서 경기 보기 →](https://ssapo.github.io/aoe2/)**

브라우저에서 바로 사용할 수 있으며, 방문자는 게임·Python·별도 앱을 설치할 필요가 없습니다. 무료로 이용할 수 있습니다.

## 무엇을 볼 수 있나요?

- **경기 기록:** 승패, 맵, 양측 문명, 상대 이름과 레이팅 변화
- **전개 비교:** 시대업 시점, 첫 병력과 오프닝, 생산·연구·건설 요청
- **자원 흐름:** 나와 상대의 보유 자원, 지원되는 경기의 검증 구간 내 자원별 수입·식량 출처
- **경기 흐름:** 시간순 명령 기록, 초기 지형 위 건설·이동 지시 표시와 기록 재생

## 사용 방법

1. 사이트를 열면 기본 계정 **ssapo**의 기록이 표시됩니다.
2. 닉네임이나 게임 서버 프로필 ID를 검색하거나 선수 바로가기로 다른 계정을 선택합니다. 이름 검색은 수집된 RM 1v1 랭킹 명단을 기준으로 합니다.
3. 경기를 선택하고 복기·수치·시대업·생산 및 연구·경기 흐름을 살펴봅니다.
4. **새로고침**은 저장된 결과를 다시 읽습니다. **지금 수집**은 선택한 계정의 공개 경기 수집을 요청합니다. 서버 준비나 분석에 시간이 걸릴 수 있습니다.

## 분석을 읽을 때

생산·건설·연구 요청은 실제 완료나 생존 병력 수와 다릅니다. 지도와 기록 재생도 실제 유닛 이동·전투를 그대로 재현한 게임 영상은 아닙니다.

공개 리플을 구하지 못하거나 파서가 지원하지 않는 경기는 분석이 없을 수 있습니다. 추정값은 추정으로 다루며, 엔진 기반 자원 분석은 확인된 구간만 제공합니다. 특정 수치만으로 승패 원인을 단정하지 않습니다.
