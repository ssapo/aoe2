# 186.6초 말 4285의 도망 차이 조사

2026-11-11 Codex. 아직 원인 미확정, 행동 수정 없음.

- DAT unit_probe로 civ 0 / master 2095의 class=9 확인. class 65 가설은 해당하지 않는다.
- save_view unit-ais로 리플 시작의 4283/4284/4285 모두 need_unit_ai=2 확인. oracle object_parts.rs unit_ai는 저장된 need_unit_ai를 직접 사용한다. factory_kind의 class 65 변경은 이 사례의 로드 경로에 관여하지 않는다.
- 최신 9개 스위치 실행 p26 (9430~9480, 정상 종료)에서 186.605~187.501초: 4283은 원본과 float32 위치 일치, 4284는 양쪽 정지. 4285만 엔진 정지/원본 이동. 기존 인계의 4283~4285 전체라는 표현을 정정한다.
- 186.381초 원본과 엔진의 4285 위치 (25.2910995,87.591507), 정찰병3428 위치 (23.1665764,88.0198975)가 일치. 4285 retarget=1244, look=672도 일치.
- 원본을 직접 읽은 구간: out_r11/a1.c 0xcf0300(생성), 0xcfcbd0 안 0xcfd0bb 이후(검색/도망), out_c/h2.c 0xd22c20 시작(검색 호출). idle는 검색이 찾은 객체가 존재하면 0xd26200을 호출한다. 타이머가 달라 호출되지 않는지, 검색이 실패하는지는 아직 분리하지 못했다.
- census 추적에 선택 ID 필터 GENIE_TRACE_OBJECT_IDS=4283,4284,4285,3428 및 ai 종류/idle timer/current action/current target을 추가. 이것은 진단 출력만 바꾸며 게임 동작은 바꾸지 않는다.
